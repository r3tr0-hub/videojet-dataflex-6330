# Sources and publication scope

The November 2026 research compared DataFlex 6330 firmware 409720.r12.SP5 (ARM) and CLARiSOFT/CLARiCOM Windows components (x86), then exercised read, preview and job upload against one printer using the diagnostic client. Each technical section identifies the evidence it used. Offline vectors reproduce selected serializers; they are not network captures.

The repository contains original diagnostics and codecs, reconstructed protocol facts, selected reference vectors and documentation. It does not contain firmware, vendor DLLs, original manuals, proprietary disassemblies, plant parameter values, operator reports, labels, credentials or artwork. Internal addresses and example job identifiers have been removed. Addresses of functions and SHA-256 hashes identify examined builds for independent reproduction.

Some research notes mention private source files or emulation inputs. Those inputs must be obtained separately from a device or lawful installation. They are not needed by the default offline test suite.
