### Что подтверждено

- **На аппарате:** два пути чтения дерева параметров, прямой TCP и Windows ZBC2; в отчётах получено по 1456 записей. Предпросмотр вернул BMP в двух запусках. Пользователь подтвердил успешную передачу задания через диагностический клиент. Это не переносится автоматически на другие версии, устройства и все команды.
- **По сравнению с ARM/x86:** фрагментация, CRC, часть сеанса, сериализация операций с заданиями, проверка допуска XML-записи и числовые ограничения. Тесты используют сохранённые синтетические векторы, а повторная эмуляция требует собственных исходных бинарников.
- **Не подтверждено на аппарате:** произвольная запись параметров, прямой TCP upload, все операции очереди и совместимость заново сгенерированных CIFF. Нативная передача готового задания и создание нового макета — разные проверки.

Каталог содержит 897 строк из объединённых источников. Он не совпадает с живым деревом: пути могут зависеть от комплектации или присутствовать только в справочных данных. В опубликованном каталоге нет рабочих значений.
